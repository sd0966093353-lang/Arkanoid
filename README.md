# 餘燼俱樂部

一款暖色系的打磚塊網頁遊戲。接住彈跳的小球，敲碎磚塊、收集道具，挑戰更高關卡與個人紀錄。

## 開始遊戲

直接用瀏覽器開啟 `index.html` 即可遊玩，不需要安裝套件或啟動伺服器。

## 操作方式

- **移動板子：** 鍵盤 `←` / `→` 或 `A` / `D`，也可以移動滑鼠控制板子。
- **發球：** 按 `空白鍵` 或點擊遊戲區；手機上可點擊「發球」按鈕。
- **手機操作：** 使用遊戲下方的左右方向按鈕移動板子。

## 遊戲特色

- 每清完一關，分數增加 1 分。
- 關卡逐漸增加磚塊耐久度，並改變磚塊排列。
- 磚塊有機會掉落四種道具：
  - **分裂球：** 增加球的數量。
  - **加長板子：** 暫時加寬板子，增加接球範圍。
  - **加速球：** 提高球速。
  - **慢速球：** 降低球速。
- 有三次失誤機會；球掉出畫面會失去一次生命。
- 個人最高分會儲存在目前瀏覽器的本機儲存空間。
- 支援桌面與手機瀏覽器。

## 紀錄說明

最高分使用瀏覽器的 `localStorage` 保存，只會留在目前使用的瀏覽器與裝置中。清除網站資料或改用其他瀏覽器後，紀錄不會自動同步。
